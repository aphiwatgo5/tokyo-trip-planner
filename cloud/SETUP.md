# ☁️ ติดตั้ง Cloud Sync — Google Sheets + Apps Script (5 ขั้น ~5 นาที)

ทำครั้งเดียวในบัญชี Google ของคุณ → แอปทุกเครื่อง (คอม/มือถือ) ใช้ข้อมูลชุดเดียวกันผ่าน Sheet ที่คุณเป็นเจ้าของ

## ขั้นที่ 1 — สร้าง Spreadsheet
1. เปิด [sheets.new](https://sheets.new) (เข้าบัญชี Google ของคุณ)
2. ตั้งชื่อ เช่น `Tokyo Trip Planner — DB`
3. คัดลอก URL ของ Sheet เก็บไว้ (จะใช้ในแอป "ลิงก์เปิด Sheet" — ไม่บังคับ)

## ขั้นที่ 2 — วางสคริปต์
1. ใน Sheet: เมนู **Extensions → Apps Script**
2. ลบโค้ดตัวอย่างในไฟล์ `Code.gs` แล้ววางเนื้อหาทั้งหมดจากไฟล์ **`cloud/Code.gs`** ใน repo นี้
3. กด **Ctrl/Cmd+S** บันทึก

## ขั้นที่ 3 — สร้างโทเคน (SECRET)
1. ในหน้า Apps Script: เลือกฟังก์ชัน `setupSecret` ในแถบด้านบน แล้วกด **▶ Run**
2. ครั้งแรกจะขออนุญาต — กด **Review permissions → เลือกบัญชี → Advanced → Go to … (unsafe) → Allow**
   (เตือน "unsafe" เป็นเพราะสคริปต์ยังไม่ผ่านการรีวิวของ Google — ปกติสำหรับสคริปต์ส่วนตัว)
3. เปิด **Execution log** — จะเห็นบรรทัด `สร้าง SECRET แล้ว: tp-xxxxxxx…`
4. **คัดลอกโทเคน** นั้นเก็บไว้

## ขั้นที่ 4 — Deploy เป็น Web App
1. กด **Deploy → New deployment** (ปุ่มสีน้ำเงินขวาบน)
2. กดไอคอน ⚙️ → เลือก **Web app**
3. ตั้งค่า:
   - Description: `trip-planner api`
   - Execute as: **Me**
   - Who has access: **Anyone** *(จำเป็น — GitHub Pages เรียกจากโดเมนอื่น และมีโทเคนคุ้มกันอยู่แล้ว)*
4. กด **Deploy** → คัดลอก **Web app URL** (ลงท้าย `/exec`)

## ขั้นที่ 5 — เชื่อมกับแอป
1. เปิดแอป → ปุ่ม **☁️** บนแถบเครื่องมือ
2. วาง Web App URL + โทเคน → ตั้งชื่อเครื่อง (เช่น `MacBook`, `iPhone`) → บันทึก
3. กด **⬆️ ฝากเดี๋ยวนี้** ครั้งแรก → กลับไปดู Sheet จะเห็นแท็บ `_trips` / `_db` / **`แผน·<ชื่อทริป>`** (มิเรอร์อ่านง่าย)
4. เครื่องอื่น: เปิดแอป → ☁️ → ใส่ URL+โทเคน เดียวกัน → เลือกทริปจาก dropdown **☁️ ทริปจากคลาวด์…**

## ใช้งานประจำวัน
- **ซิงก์อัตโนมัติ** (ค่าเริ่มต้น): แก้อะไรในแอป → ฝากขึ้นหลัง ~4 วิ · เปิดแอป → ดึงเวอร์ชันใหม่ลงมา
- สถานะปุ่ม ☁️: ปกติ = ซิงก์แล้ว · **☁️…** = รอฝาก · **☁️!** = ผิดพลาด (กดเข้าไปดูสาเหตุ/กดฝากซ้ำ)
- ออฟไลน์: แอปใช้ข้อมูลในเครื่องได้ตามปกติ — เน็ตกลับมาค่อยฝากขึ้นเอง
- ถ้าอีกเครื่องแก้ไปก่อน: แอปจะ**ถามก่อน** (เอาของบนคลาวด์ / ฝากอันนี้ทับ) ไม่เงียบทับกัน
- แท็บ `แผน·…` ใน Sheet = **อ่านอย่างเดียว** สำหรับแชร์ดู — แก้ต้องแก้ผ่านแอปเท่านั้น (แก้ตรงนั้นจะถูกเขียนทับรอบถัดไป)

## หมายเหตุ / แก้ปัญหา
- แก้โค้ด `Code.gs` แล้วต้อง **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** ทุกครั้ง ไม่งั้น URL ยังใช้รุ่นเก่า
- เปลี่ยนโทเคน: ลบ Script Property `SECRET` แล้วรัน `setupSecret` อีกครั้ง + อัปเดตในแอปทุกเครื่อง
- โควตา Apps Script ส่วนตัวเหลือเฟือสำหรับงานนี้ (เซฟครั้งละ ~100–300 ms)
- ความปลอดภัย = ระดับ "มีโทเคนถึงเรียกได้" เหมาะกับใช้ในครอบครัว ไม่ใช่ข้อมูลระดับแบงก์
